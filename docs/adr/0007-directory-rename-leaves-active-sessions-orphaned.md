
# ADR 0007: 目录重命名后放任活动会话失联

## 状态
Accepted

## 背景

目录 ID 由相对路径派生（`encodeID(relPath)`），图片 ID 由相对路径加修改时间派生。
重命名目录会改变该目录的 ID，并连带改变其下所有图片的 ID。而内存中的筛选会话
以目录 ID 为索引、以图片 ID 为键存储操作记录（actions/durations/undoStack），
因此重命名会使绑定在该目录上的活动会话失联。

会话没有显式「结束」概念，仅靠空闲时长与数量保留自动清理。

## 决定

**允许重命名有活动会话的目录，不迁移会话；旧会话随即不再可达，随内存清理自然消失。**

## 考虑过的选项

- **阻止重命名**（有活动会话时拒绝）：会话无法主动结束，用户没有解锁手段，交互上不可行。
- **迁移会话**：需重建会话内整个图片集合并重映射所有以图片 ID 为键的状态
  （actions/durations/undoStack），代价与风险远超收益。
